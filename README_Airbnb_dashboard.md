# 🏡 Global Airbnb Performance Dashboard

An interactive Power BI dashboard exploring Airbnb listings, pricing, guest ratings, reviews, and host trust indicators across 10 cities.

## 📌 Project Overview

This project analyzes Airbnb listing and review data to explore market distribution, pricing patterns, rating differences, review activity, and host verification indicators. The dashboard is organized into three report pages so viewers can examine the data from different perspectives.

## 📊 Dashboard Pages

### 1. Overview
- Summary KPIs for listings, cities, hosts, property types, and reviews
- New listing trends over time
- City-level market share
- Average prices by room type

### 2. Ratings
- Guest rating comparisons across cities
- Rating patterns to support city-level comparisons

### 3. Reviews
- Review frequency and seasonality
- Review activity across the selected categories
- Host identity and profile verification indicators

## 🧰 Tools Used

- **Power BI Desktop** — data modeling, DAX measures, and dashboard visuals
- **Microsoft Excel** — dataset file and data preparation, where applicable
- **GitHub** — project documentation and portfolio presentation

## 🗂️ Dataset

The dataset used in this project was obtained from Maven Analytics.

**Source:** [Airbnb Listings & Reviews Dataset — Maven Analytics](https://mavenanalytics.io/data-playground/airbnb-listings-reviews)

The dataset contains Airbnb listing and review information used to analyze listing trends, city-level market share, pricing, guest ratings, review frequency, seasonality, and host trust indicators.

> **Note:** The dataset is not included in this repository because of its large file size. Use the source link above to access the original dataset.
